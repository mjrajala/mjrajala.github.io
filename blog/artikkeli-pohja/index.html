Noindex-pohja

Tämä on tulevien blogipostausten artikkelirunko

Tätä sivua ei ole tarkoitettu löydettäväksi hakukoneissa. Se on tekninen pohja, josta varsinaiset artikkelit voidaan tehdä omille URL-osoitteilleen.

Rungossa valmiina:
  • oma URL artikkelille
  • title + meta description
  • canonical
  • Article-schema
  • tila kirjoittajalle, ingressille, leipätekstille ja CTA-linkeille
