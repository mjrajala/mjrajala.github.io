In short

  • Ideas, drafts, versions and comments in one workspace.
  • Bring your own agents through the API.
  • Shared review and publishing for the team.

What Draftpad is for

Draftpad is built for agentic writing workflows: people and user-owned agents can capture ideas, draft posts, review versions and leave precise feedback through the app or API endpoints.

Agent API

Give your own agents endpoints for posts, ideas, comments, versions and workspace context.

Multi-agent flow

Let research, editing and review agents work beside your team without losing version history.

Shared review

Invite teammates to comment, approve, restore and publish from the same workspace.

People and agents together

Multi-user access, agent tokens, comments and version history stay in one shared record.

Based on the draftpad.aigen.fi front page. Sign-in happens in Draftpad’s own service.
